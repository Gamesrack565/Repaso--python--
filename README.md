## Contenido del Temario

Actualmente, el repositorio abarca los fundamentos iniciales de Python, organizados a partir del notebook `Primeros_pasos.ipynb`:

### 1. Variables, Tipos de Datos y Operadores
- **Conceptos de Datos y Variables:** Definición de valores concretos y asignación dinámica de variables.
- **Tipos Fundamentales:** Uso de enteros (`int`), números con punto decimal (`float`), cadenas de texto (`str`) y booleanos (`bool`).
- **Sintaxis y Reglas:** Normas para el nombramiento de variables (case-sensitive, uso de letras y guiones bajos) y la convención para declarar constantes usando mayúsculas.
- **Funciones Básicas:** Uso de `print()` para la impresión en consola y `type()` para revisar el tipo de variable.

### 2. Strings (Manejo de Cadenas)
- **Propiedades Básicas:** Entendimiento de las cadenas como conjuntos de caracteres con índices, el uso de cadenas multilínea y la inmutabilidad de los strings originales.
- **Concatenación y Formateo:** Unión de variables de texto mediante el método operador (`+`) y el método moderno utilizando *F-Strings*.
- **Técnica de Slicing:** Extracción de fragmentos de texto específicos utilizando la sintaxis `[inicio : fin : paso]`.
- **Métodos y Funciones de Cadenas:**
  - Medición de la longitud de cadenas con la función `len()`.
  - Conversión a mayúsculas y minúsculas con `.upper()` y `.lower()`.
  - Sustitución de texto con el método `.replace()`.
  - Eliminación de espacios y caracteres al inicio y final con `.strip()`.
